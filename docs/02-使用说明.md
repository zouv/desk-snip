# 02 · 使用与维护

## 构建与运行

开发环境需要 Windows、.NET SDK 与 .NET Framework 4.8 Developer Pack。双击 dev.bat 构建并运行，也可使用：

```bash
sh manager.sh doctor
sh manager.sh dev
```

免安装包解压后双击 DeskSnip.exe，不需要 .NET SDK；运行需要 .NET Framework 4.8。程序启动后默认只在托盘运行，不自动打开主界面；可从托盘菜单“打开主界面”或再次启动程序打开。托盘图标设为隐藏时，启动会显示主界面以免找不到入口。

## 设置与参考项

设置窗口提供 15 类导航。系统、外观、截图、钉图、保存及标注按参考图分组；动作、内置快捷键、鼠标和全局鼠标各有独立页，保留录屏及联网服务页。灰色项说明尚缺少的功能，完整清单见 [06-设置参考对照](06-设置参考对照.md)。

修改在点击“保存设置”后生效，切页保留草稿。非默认项加粗，“恢复本页默认”只重置本页；截图/钉图两页的“钉图时同时复制”共用同一值，从任一页修改或恢复都会同步。导出/导入包含可移植偏好，排除本机目录、代理连接信息和服务凭据。

系统页的“界面语言”支持简体中文、English 与跟随系统，点击“保存设置”后更新已打开窗口和托盘，重启仍沿用选择；跟随系统在中文系统用中文，其它系统用英文。界面切换保持用户标题、文件名、快捷键、校对/标注/表格/公式/文档内容，OCR 和翻译服务的语言单独设置。

系统页可设置托盘单击/双击/中键动作、OCR 默认排版/语言与代理，并选择截图/复制/钉图识别是否先显示确认窗口。开机启动和图像文件右键菜单仅在保存相应设置时写入当前账号；移动程序目录后需关闭再开启相关选项并保存，以更新入口。图像右键可通知已运行的 DeskSnip 钉图。其它界面语言、管理员启动、自动更新、Socks5及文本/文件/动态/窗口钉图仍未开放。

“快捷键 / 动作”逐行按键、托盘显隐及名称可编辑，支持添加、删除、清空和忽略进程名单；“内置快捷键”按八个场景分页，已支持类型可改键并合并小键盘数字。点击输入框后按组合键，Backspace/Delete 或右侧 × 清空；清空后该绑定停用，同场景重复键位会阻止保存。

“鼠标”按动作选修饰键、滚轮/单击/双击/拖动/侧键。Ctrl 单击多选和 Ctrl 拖出图片分开执行；关闭、销毁仍遵守锁定与确认。“全局鼠标”初始未绑定，保存修饰键 + 拖动组合后可直接框出区域做截图、识别、长截图或 GIF；可显示遮罩并按进程跳过。联网动作先打开相应确认窗口，点击请求才发送。

“标注”可配置共享颜色/调色板、工具记忆与排列、画笔光标/平滑/Shift 直线、二次编辑、序号补号/从 0 开始/进程连续编号、折线/文字样式和自动水印；对应工具在就地标注和完整编辑器采用这些偏好。未开放的序号引线、缩略图和图内文本调整保留禁用条目。

## 截图与取色

1. 点击“截取屏幕”或按 Ctrl+Alt+A，桌面冻结后拖动框选。未框选时移动鼠标会自动框住光标下的窗口或 UI 元素（含浏览器/资源管理器），点击即可选中；Tab 在元素与窗口之间切换，滚轮切换父子范围。Ctrl+A 首次选择鼠标所在屏幕，再次选择全部虚拟桌面。
2. 选区内部拖动移动，Shift 限制水平/垂直移动；拖动八个边角控制点调整大小，Shift 保持正方形、Alt 以中心对称调整；调整时按住 Space 临时移动，松开后继续调整。
3. 方向键移动 1 px；Shift+方向键收缩对应的边，Ctrl+方向键扩展对应的边。滚轮等比例缩放；点击左上角位置/尺寸标签展开 X/Y/宽/高、锁定比例和九宫格。点击“应用”或在输入框按 Enter，四项一起校验，越界、溢出和无效尺寸不改变选区。Esc 先收起尺寸输入，再按取消截图；未完成选区时直接退出。
4. Enter、双击选区或 Ctrl+C 直接复制图片；Ctrl+T 钉图、Ctrl+S 另存为。白色圆角工具条靠选区右下方，空间不足时移到上方或屏幕内；图标悬停显示操作与快捷键。形状/画笔/文字/马赛克分组的主图标直接进入组内默认标注工具，右侧箭头或右键才展开其他工具；序号、箭头、摄像头为独立按钮。点击摄像头或按 G 在当前窗口切换到录屏工具栏，再点“使用此区域”进入录制设置。标注期间选区固定，不打开独立编辑窗口；Esc 先取消当前标注交互/选择，再取消截图（不再二次确认）。非拖动时 Space 切换浮动工具显隐。
5. 默认未框选时显示像素放大镜，框选后按住 Alt 显示，M 临时切换常显；辅助线和放大镜的默认显隐、倍数/网格/坐标/平滑缩放在截图设置调整。Shift 按“启用颜色格式与顺序”循环，P 切换桌面物理坐标与选区相对坐标。C 复制颜色、Alt+C 复制坐标后退出；W/A/S/D 微调光标 1 px。F1 切换提示，反引号临时切换截图中的鼠标指针。
6. 截图选区的标注工具条按形状、线条、画笔、文字、马赛克、遮挡、橡皮擦与聚光/放大分组，序号直接选择。点击分组图标直接使用该组当前默认工具；点击右侧箭头或右键打开列表切换，选择会按组记住并在重启后保留。切换到工具后，工具条下方出现该工具的子操作栏：形状提供矩形/椭圆/圆角矩形、填充、线型、线宽、圆角半径与颜色；箭头/线条提供线型、线宽、箭头样式与颜色；画笔/高亮提供线宽、透明度与颜色；文字/水印提供字体、字号、粗体/斜体、文字底色与颜色。点击同类标注即可选中；选中形状显示四角调整柄，拖动可改位置和尺寸；箭头/直线显示端点柄，可调整起点和终点。撤销/重做和“标注样式”（颜色、线宽、填充、文字底色、线型、箭头、透明度、效果、粗体、斜体、字体、字号、方角/圆角）作用于当前画布或选中对象。文字工具在图片位置直接输入，Enter 提交、Shift+Enter 换行、Esc 取消；文字可选颜色、字体、字号和粗体/斜体。打开图片或历史进入的完整编辑器同样提供这些样式。所有原有标注类型仍可用。多行文本按画布右边界换行；折线逐点点击，Enter/双击结束；水印中的 {time} 在创建时展开。
7. 切回同类工具点击已有标注即可选中（工具栏不再提供独立的“选择 / 移动”按钮）。拖动/方向键移动；Alt 拖动复制，Shift 限制水平/垂直移动；Ctrl+D 生成偏移副本，Delete 删除。选中对象时调整颜色/粗细/字体字号会修改该对象；Esc 取消选中，再设置样式用于新标注。
8. 文字选中后双击、Enter 或点击“修改文字”重编辑；提交空白文本移除对象，取消保留原值。编辑文字时 Ctrl+C/Delete 只操作文字。
9. Ctrl+Z / Ctrl+Y 撤销重做；清空按钮或 Ctrl+Shift+Z 清空标注，沿用可撤销规则。截图内 Ctrl+C 复制图像、Ctrl+S 另存为、Ctrl+P 钉图；完整编辑器同样支持。输出保持原像素尺寸，选择框和未提交拖动预览不进入导出。

数值输入框中 Ctrl+A/C 等保持正常文字编辑行为，Enter 只应用数值。截图设置的“自动识别选区”可选元素/窗口/不检测，并设置边距、点击外部扩展及鼠标双击/中键/滚轮动作；元素模式通过 Win32 与后台 UI Automation 查询覆盖浏览器/资源管理器等无子 HWND 的控件，查询不阻塞鼠标移动；个别自绘区域可能只识别到容器。选区竖栏提供形状、窗口/控件、历史和重选；区域历史上限与内容历史分别为 0–99999，0 停止区域记录与读取。可选择椭圆、自由轮廓或多边形，多边形 Enter/双击结束，外部像素透明。Ctrl+Shift+S 快速保存、Shift+C 本地识别、L 长截图；联网识别/长截图图标可随次要区域隐藏，快捷键保留。

“截图预设”管理固定位置/尺寸、0–30 秒延时、指针与形状，支持复制/删除和交换宽高。固定位置的矩形/椭圆直接进入编辑，其它情况预填选区继续调整。外观页配置选框宽度/颜色/四角或八向锚点、遮罩及工具栏尺寸。HDPI 复制缩小只影响复制的截图，选区坐标和保存保持原像素。dp、自定义颜色分量模板及多窗口合成仍待补。

编辑器支持填充、实/虚/点线、透明度、四种箭头样式与效果强度；更改已选对象可撤销。输出支持 PNG/JPEG/BMP/TIFF，JPEG 质量在设置选择；重新编码不带原文件 EXIF，开启写入时仅写入软件名及当前时间。“本地隐私遮挡”检测 OCR 的手机号/邮箱并添加可撤销纯色覆盖；“识别二维码”确认后复制内容。局部橡皮擦恢复底图；智能背景补全、几何控制点缩放/旋转与标注工程保存仍待补。

## 图片钉图与历史

- Ctrl+Alt+P 钉住剪贴板图片。也可以“打开图片”，编辑后按 Ctrl+P。
- 默认过大图片适合屏幕，滚轮缩放、Alt 精细缩放、Ctrl 滚轮透明度及中键还原/切回；范围 1%–800% / 10%–100%。钉图页可配步长、缩放基准点、边框调整、默认不透明度/置顶和显示位置。
- 右键菜单提供当前/原图复制、保存、快速保存、继续标注、旋转/镜像、灰度/反色/亮度、识别、置顶、锁定和穿透；菜单采用应用主题样式，每个菜单项带图标并显示对应快捷键。选中钉图时边框显示为淡黄色渐变（越靠外越透明），按 F 可显示/隐藏该边框；不再显示右上角 ···/× 按钮。按 Space 或 E 直接在图片上打开标注工具栏，Space / Enter 完成并写回，Esc 取消；编辑期间移动、缩放、替换和关闭快捷键暂停。按 Esc 直接关闭钉图（不询问，仍受锁定关闭限制），左键双击固定复制当前图并关闭。Ctrl+V 或拖入单张图片可替换。锁定的移动缩放、鼠标关闭、按键关闭及拖拽接收可分别限制；按键/鼠标关闭确认仍用于其它关闭入口。
- 默认穿透时显示“解除鼠标穿透”工具栏，跟随钉图显隐和关闭。控制台/托盘可解除全部穿透/锁定并恢复不透明度。穿透不透明度上限、阴影、背景、平滑缩放在钉图页设置。
- 钉图独立保存原图、当前图和布局；启动恢复和关闭历史上限在设置/管理器共用，上限 0–1000，只淘汰关闭记录。恢复最近钉图可按关闭或创建时间排序。
- Ctrl 单击多选，拖动任意选中图移动全部选中图。管理器可新建/切换分组、编辑名称/颜色、批量移动/显隐/关闭/恢复/保存/移组、修改标题和“移回屏幕”。销毁和清空分组需确认，会删除恢复记录。
- 复制、保存或钉图时，图像进入历史。内容历史上限可设 0–99999，淘汰历史文件不会关闭活动钉图。标注工程不入历史，记录为合成后的 PNG。
- 显示缩放和不透明度不改变输出像素；“保存 / 复制时的图像类型”选择当前图或原始图。旋转/镜像/替换影响当前图，原图保留。

## 本地 OCR 与长截图

截图、编辑器、钉图菜单和图片历史都能进入“文字识别”。使用 Windows 已安装的 OCR 语言，不联网；未安装时在 Windows 补充组件。系统设置的默认排版/空格/标点同时用于校对窗口与直接复制；窗口可临时调整、重试、复制所选/全部及保存 UTF-8 文本。设置可指定语言、识别后直接复制、复制全部后关闭；无结果/失败仍打开校对窗口。

长截图先框选滚动内容，避开固定标题和滚动条。按 L 或选择“长截图”后，截图界面关闭但选区边框保留，并在选区左侧或右侧（按屏幕空间）显示长图面板；“自动采集”每隔约 600 ms 采集选区内的新内容并拼进长图，面板预览随新内容滚到底部，不自动操作其它窗口。面板“更多 → 方向与拼接”可切换纵向/横向、正/反方向、手工重叠、裁掉当前画面之前/之后、撤回或重新开始。匹配失败时已有结果保留，可回到最后成功位置、输入重叠像素继续。完成后 Ctrl+T 钉图、复制、保存、OCR/联网识别或编辑长图；不再打开独立的长截图窗口。当前最多 5000 万像素；自动滚动、反向自动裁剪、超长分块和竖排 OCR 待补。

长图面板获得焦点时 Enter 完成并复制、Ctrl+S 保存、Ctrl+Z 撤回、Esc 取消；长图另存为使用统一图片保存设置。

## 区域录屏与剪辑

1. 点击“录制区域”或 Ctrl+Alt+R，框选并确认区域。
2. 选择 MP4/GIF/WebP、帧率（最高 60，GIF 最高 15）、指针、倒计时与输出位置；声音开关直接显示。展开“声音设备与高级选项”选择独立设备、FFmpeg、画质和最终导出编码器，开始后参数固定。
3. 录制区域保留蓝色边框，白色单行控制条靠右下方显示时长、实际设置的 FPS 和格式。左侧点状握把可拖动控制条；格式下拉查看区域与指针参数，声音图标查看两路开关状态。暂停按钮变为继续图标；Ctrl+Alt+R 同样切换，暂停时间不计入成片。
4. 点击红色停止图标“停止并保存”，等待编码完成；保存中显示进度并禁用操作。工具栏模式在截图设置中选择“每次选择 / 始终显示 / 隐藏”；隐藏时从托盘“停止并保存录制”停止，也可重新显示工具栏。隐藏托盘时强制保留工具栏。关闭工具栏或正常退出也会保存。
5. 控制条“更多”提供确认后的“放弃录制”与“重新录制”。刚停止的录制会以无标题栏浮层覆盖在录制区域上直接回放/剪辑，拖动时间轴跳转，用秒数或当前位置设置开始/结束，输入裁剪 X/Y/宽/高，选择 0.2–2x、两路音量与画质后导出 MP4/GIF/WebP；浮层可用“关闭”或 Esc 退出。历史录像仍用普通“回放与剪辑”窗口。可复制录制文件或取消导出；失败不替换旧目标。

开启“编码后退出录制界面”保存后返回主窗口，关闭时自动打开成片；回放导出也可按该偏好自动关闭。保存页可配置独立 MP4 快速录制目录/文件名/同名覆盖，模板尺寸使用实际选区尺寸。保存后复制文件/路径同样用于录制。

基础无音频 MP4/GIF 仍可仅使用 Windows Media Foundation 与流式 GIF。声音、WebP、剪辑、硬件最终导出和恢复需要本机 FFmpeg/ffprobe，在“设置 → 录屏”指定 ffmpeg.exe 或放入 PATH；应用不下载或随包附带本机 FFmpeg。MP4 为偶数尺寸，右/下边缘可能缩减 1 px，最大单边 4096、829 万像素；直接 GIF 最大 207 万像素、15 FPS、256 色，基础 MP4 转 GIF 默认 10 FPS。GIF/WebP 不含声音。

有 FFmpeg 时录制保存约 2 秒片段及两路 WAV，停止后合并并导出。“录制恢复”可恢复已完成片段、修复中断 WAV，素材保留以继续剪辑；删除素材不删除已导出成片。硬件选择只作用于最终导出，会实际试编码，失败回退软件；捕获片段仍用 Windows MF。预览音量最高 100%，导出可到 200%。

工具条尽量放到选区外并向 Windows 请求排除捕获。大区域帧率、实际声卡同步/长时稳定和断电场景仍需实测，最后未收尾片段可能丢失。键鼠效果、摄像头和拖动剪辑手柄尚未实现。

## 联网识别与翻译

先在“设置 → 联网服务”填写支持 [DeskSnip 服务协议](04-联网服务协议.md) 的 HTTPS 地址、密钥或环境变量名与超时；在“设置 → 系统”选择翻译的源语言和目标语言。密钥由 Windows 为当前账号加密，环境变量优先；留空密钥保留原值，勾选清除才删除。现有服务商 API 需要按协议适配。

从截图、编辑器、钉图或历史进入“联网识别”，也可用控制台“联网识别 / 翻译”读取剪贴板图像或文字。选择文字、翻译、表格、公式或文档，检查“发送原图”和请求文字，再点击“请求服务”；打开窗口不会请求服务。失败、超时、取消保留原图和旧结果。

- 文字/译文可直接校对、复制和保存文本。
- 表格双击编辑，Ctrl/Shift 选择连续矩形，可插删行列、合并/拆分、排序及撤销重做，复制全部/选区，导出 XLSX/CSV/TSV。合并只显示左上格，底层内容拆分后恢复；插删行列会拆分合并。XLSX 固定边框/左对齐、首行加粗，全部单元格作为文本保存；CSV/TSV 对疑似公式文本加单引号。
- 公式列表逐条编辑 LaTeX，实时本地预览。可选择复制定界符，导出多条源码或当前公式 PNG；复杂或不支持语法保留源码并给出预览反馈。
- 文档可编辑 Markdown，预览基础标题/列表/表格/公式和服务配图，导出带配图 ZIP、源码或 Word。Word 公式保留 LaTeX 源码；完整 Markdown 排版、PDF、整篇 LaTeX 与更多公式格式待补。

成功结果、原图和编辑会保存到本机，控制台“恢复识别结果”无需联网继续编辑。仅保留最近保存的一份；本地模拟服务已验证协议，实际服务效果取决于所配置服务。

## 保存、快捷键与退出

保存页分别配置手动图片、快速图片、快速 MP4 和自动留档的模板/格式/覆盖规则。变量支持 {date}/{time}/{width}/{height}/{kind}/{title}，日期/时间可指定格式，如 {date:yyyy-MM-dd}；预览采用示例尺寸，不创建文件。开启“记住扩展名”后，手动保存成功才更新默认格式。JPEG 质量 0–100，0 为最低；PNG/BMP/TIFF 无损，JPEG/TIFF 可写入软件名和时间 EXIF。

手动/快速保存后可复制文件、路径或两者，录制完成、历史另存、GIF 转换、剪辑导出和恢复也使用该规则；快速图片保存可显示托盘通知并点击定位或复制。自动保存先开启总开关，再选择截图/复制/钉图/保存/识别/翻译/长截图触发类型。自动留档目录独立，文件含 DeskSnip-auto- 标识；仅清理本应用登记文件，最新一张始终保留。年龄清理关闭后不按天数删除，容量限制仍有效；禁用关联输入保留草稿。

三组基础热键之外，可为快速截图、长截图、剪贴板 OCR、钉图显隐/救援、打开控制台和恢复钉图添加全局键。修饰键支持 Ctrl/Alt/Shift/Win，主键如 A/F9；重复或占用时提示，窗口/托盘仍可用。快捷键输入框聚焦后按组合键即完成设置并移出焦点；Esc / Backspace 取消并恢复原值，Delete 或 × 清空。设置窗口打开期间暂停本应用全局热键，因此已注册的组合也能录入。托盘可暂时禁用/恢复热键，动作配置保留。取消截图不再弹出二次确认。

从托盘或窗口“退出”正常结束程序，等待录制保存并取消/等待回放导出、恢复和联网请求。程序默认只在托盘运行；第二次启动唤起已有实例并显示主界面。--pin-file 发送图片路径，--background 保留后台启动兼容（托盘可用时不打开主界面）。脚本 stop 使用自有命名事件请求退出，不强杀进程。JavaScript/通用 IPC 与全局手势仍待补。

## 验证与打包

```bash
sh manager.sh verify
sh manager.sh package
```

构建、测试、文档检查通过后，打包到 dist/dev 与 dist/release。Release 的 unpack 目录可直接运行；zip 解压即用。Windows 的 *.bat 直接调用 PowerShell，无需 Git Bash，verify 的文档检查仍需可用的 Bash。

## 数据与维护

- 数据在 `%LOCALAPPDATA%\DeskSnip`：settings.json 配置，history.json 和 history/ 为内容历史，recordings/ 为默认成片，pins.json 和 pins/ 为独立钉图，captures.json 为选区/预设，recording-drafts/ 为录制素材。
- recognition/last-session.json 保存最近识别原图、请求文字和校对结果；credentials/recognition.dat 为当前 Windows 账号加密密钥。迁移数据到不同账号后重新填写密钥。
- 卸载免安装程序不删除用户数据；迁移时复制数据目录。
- 测试使用独立临时数据；真实桌面截图仅存忽略目录。
- stop 正常请求退出并等待，超时手动关闭，不强杀。
- 版本与目标框架集中在 Directory.Build.props；命令以 manager.sh help 为准。
- 开发测试可用 DESK_SNIP_DATA_DIR 指定独立数据目录，不自动迁移已有数据。目录必须独立且不经过符号链接/联接点。
- 历史淘汰不清理 recordings/ 的原文件；默认录屏原文件和历史副本各占一份空间。配置损坏时保留原文件，提示并使用默认值。

## 验证边界

自动测试使用合成图像/视频/音轨，验证选区、标注像素、钉图存储、OCR、长图重叠、编码/解码、暂停、恢复、偏好与原子保存；B8 用本地模拟服务验证五类请求、失败/取消/超时和密钥，Office SDK 独立校验 XLSX/Word。合成 WPF 图检查最小窗口、选区边缘及模拟缩放；录屏控制条与边框实际创建窗口，检查原生尺寸/位置、穿透/不激活标志和收尾关闭，录制输入仍为合成帧。真实启动/正常退出已有验证；桌面自动化仍无法可靠输入、捕获和激活，人工框选、鼠标菜单与真实录屏仍待验收。混合 DPI、多屏、HDR、游戏、真实声卡同步和具体服务商识别效果尚未通过专项验收。
