# 02 · 使用与维护

## 构建与运行

开发环境需要 Windows、.NET SDK 与 .NET Framework 4.8 Developer Pack。双击 dev.bat 构建并运行，也可使用：

```bash
sh manager.sh doctor
sh manager.sh dev
```

免安装包解压后双击 DeskSnip.exe，不需要 .NET SDK；运行需要 .NET Framework 4.8。程序常驻托盘，首次显示控制台。

## 截图与取色

1. 点击“截取屏幕”或按 Ctrl+Alt+A，桌面冻结后拖动框选。Ctrl+A 选择整个虚拟桌面。
2. 选区内部拖动移动，外部拖动重新选区。方向键移动 1 px；Ctrl+方向键 10 px；Shift+方向键改变宽高。尺寸按物理像素显示。
3. 光标位置显示 HEX 颜色，Ctrl+C 复制颜色；Enter 或双击选区进入编辑，Esc / 右键取消。
4. 编辑器选择矩形、椭圆、直线、箭头、画笔、高亮、文字、序号、马赛克或遮挡，选择颜色和粗细后在图上操作。文字点击后输入；序号点击添加。
5. Ctrl+Z / Ctrl+Y 撤销重做；清空标注也可撤销。Ctrl+C 复制图像、Ctrl+S 另存为、Ctrl+P 钉图。输出保持原像素尺寸，显示缩放只影响预览。

支持 PNG、JPEG（95 质量）和 BMP 输出；重新编码不带入原文件 EXIF。文字字号随粗细变化，已有标注暂不支持独立选择和修改。需要完全遮挡内容时使用“遮挡”工具与纯色，输出结果请自行检查。

## 图片钉图与历史

- Ctrl+Alt+P 钉住剪贴板图片。也可以“打开图片”，编辑后按 Ctrl+P。
- 图片过大时先适合屏幕。拖动移动、滚轮缩放；Ctrl+滚轮调整透明度，最低 15%。
- 右键菜单提供复制、保存、再次标注、旋转 90°、水平/垂直镜像、锁定与鼠标穿透。锁定防移动和缩放；仍可从菜单关闭。
- 控制台和托盘的“解除全部穿透 / 锁定”恢复操作和不透明度。“显示 / 隐藏全部钉图”保留图像窗口。
- 本次运行可恢复最近关闭的 10 张钉图；重启后可从历史重新钉图。活动钉图的布局和显示状态尚未跨启动恢复。
- 复制、保存或钉图时，图像进入历史。历史条数可设为 1–1000；淘汰历史文件不会关闭活动钉图。原图标注工程不入历史，记录是合成后的 PNG。
- 显示缩放与透明度不改变复制/保存的像素；旋转与镜像会改变当前钉图输出。

## 区域录屏与 GIF

1. 点击“录制区域”或 Ctrl+Alt+R，框选并确认区域。
2. 选择 MP4 或 GIF、帧率、指针与输出位置，点击“开始录制”。默认位置为本机数据目录，也可在设置指定默认目录。
3. 控制条可暂停/继续；录制时 Ctrl+Alt+R 同样切换暂停状态。暂停时间不计入成片。
4. 点击“停止保存”，等待编码完成。关闭控制条或正常退出应用也会结束并保存录制。
5. 历史中可查看与另存为；MP4 可“导出 GIF”，默认 10 FPS。GIF 预览可播放/暂停。

当前录画面和可选指针。MP4 使用系统 H.264 编码器，GIF 使用流式 RGB332 / LZW，无需 FFmpeg。MP4 需要偶数尺寸，会从选区右侧/下侧最多缩减 1 px，最大边长 4096、总像素 829 万；GIF 最大 207 万像素、15 FPS、256 色。录制和转换使用同目录临时文件，成功后才发布。

工具条尽量放到选区之外，并向 Windows 请求排除捕获；该行为仍需桌面实测。大区域的编码帧率受实际机器速度影响。音频、首尾剪辑、硬件编码选择、中断/断电恢复、WebP 尚未实现。

## 设置与退出

设置支持三组全局热键、录制帧率、默认格式/目录、历史上限、指针和关闭时收起托盘。快捷键示例为 Ctrl+Alt+A；修饰键支持 Ctrl / Alt / Shift / Win，主键使用 WPF Key 名称，例如 A 或 F9。重复键或无效键会提示；已被其他程序占用时，主窗口显示冲突，窗口和托盘入口仍可使用。

从托盘或窗口“退出”正常结束程序。第二次启动会唤起已有实例。开发脚本 stop 通过自有命名事件通知退出，等待录制保存，不强杀进程。

## 验证与打包

```bash
sh manager.sh verify
sh manager.sh package
```

构建、测试、文档检查通过后，打包到 dist/dev 与 dist/release。Release 的 unpack 目录可直接运行；zip 解压即用。Windows 的 *.bat 直接调用 PowerShell，无需 Git Bash，verify 的文档检查仍需可用的 Bash。

## 数据与维护

- 程序目录与用户数据分离，配置和历史在 `%LOCALAPPDATA%\DeskSnip`；settings.json 为配置，history.json 为索引，history/ 保存 PNG/MP4/GIF，recordings/ 保存默认录屏原文件。
- 卸载免安装程序不删除用户数据；迁移时复制数据目录。
- 测试使用独立临时数据；真实桌面截图仅存忽略目录。
- stop 正常请求退出并等待，超时手动关闭，不强杀。
- 版本与目标框架集中在 Directory.Build.props；命令以 manager.sh help 为准。
- 开发测试可用 DESK_SNIP_DATA_DIR 指定独立数据目录，不自动迁移已有数据。目录必须独立且不经过符号链接/联接点。
- 历史淘汰不清理 recordings/ 的原文件；默认录屏原文件和历史副本各占一份空间。配置损坏时保留原文件，提示并使用默认值。

## 验证边界

目前自动测试使用合成图像和录制帧，验证尺寸、颜色/方向、编码/解码、GIF 帧数/延时、暂停时长和原子保存。真实进程启动、读取窗口控件及正常退出已验证；桌面自动化的画面捕获与激活持续失败，框选、菜单、钉图穿透及完整录屏交互待验收。多屏混合 DPI、HDR、受保护窗口与游戏画面没有通过专项验收。
