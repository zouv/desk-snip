# 06 · 设置参考图对照

逐项对应两组六图：侧栏、System、Appearance、Screenshot、Pin、Save，以及 Mark、Shortcuts/Actions、Built-in Shortcut、Mouse、Global Mouse。**已接入**表示可保存且有实际消费入口；**部分**表示已提供常用行为并列出差异；**不可用**表示条目在界面保留、禁用并说明原因。状态不是 PixPin 全功能完成度。

设置仅在点击「保存设置」后生效；切页保留草稿，「恢复本页默认」只影响当前页。非默认项加粗，导入导出支持新增偏好；本机目录、代理连接参数、服务地址及密钥不导出。

## 验证边界

独立数据的配置往返、校验、命名、清理、代理处理器、钉图动作、菜单及布局测试覆盖上述接线。开机后真正自启、不同系统版本的资源管理器菜单、托盘鼠标、实际屏幕 DPI 与真实录屏仍需桌面实测。不可用项保留在开发计划中，不按已实现统计。

第二组设置的 270 项全量测试、零警告严格编译和文档检查通过；输入与设置草稿覆盖别名/小键盘冲突、旧配置、鼠标组合、单击/拖动、清空与恢复。深浅主题、1020/760 宽及页首/页底使用独立合成预览核对，鼠标组合在最小窗口完整显示，滚动内容限制在正文区域。PixPin 实机查看尚未完成：用户显示设置窗口后，操作工具再次报告被物理 Escape 中止，本轮已停止桌面操作；图中未展开的下拉选项不宣称已经逐项实机核对。
