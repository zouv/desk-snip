# 03 · PixPin 功能对照

参考来源：[PixPin 官方使用手册](https://pixpin.cn/docs)，查阅日期：2026-11-12。已查阅功能章节与设置章节，以下按行为整理，避免把相同入口重复当作功能。

本项目独立实现公开行为，使用自制资源。表中的“基础 / 会员 / 测试版”指 PixPin 的来源限制，不是 DeskSnip 的收费设计。商业账号、支付及发票不属于自用桌面工具范围。完成状态必须以源码和验证为准。

## 范围与状态

- M1：截图、常用标注、图片钉图、基础录屏、历史、托盘和可配置快捷键。
- M2 至 M6：见 [ROADMAP.md](../ROADMAP.md)。混合阶段表示先做常用子集，再补高级参数。
- “已实现”表示对应行为有代码与基本验证；“部分实现”必须说明差异。未实测环境不计作验收。
