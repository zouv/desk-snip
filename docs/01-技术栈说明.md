# 01 · 技术栈说明

## 架构与选型

| 职责 | 技术 | 理由 |
|---|---|---|
| 语言与运行时 | C# / .NET Framework 4.8 / x64 | 与 desk-pins 一致，系统运行时，免安装分发 |
| 界面 | WPF | 多窗口、图像绘制、输入事件与自定义工具栏 |
| 桌面接口 | Win32 P/Invoke | 热键、物理像素、无激活显示与鼠标穿透 |
| 静态截图 | 系统 GDI | 第一版兼容性优先，冻结桌面后框选 |
| 视频 | Windows Media Foundation | NV12 → H.264 / MP4，系统解码后流式转换 GIF |
| 动图 | 独立 GIF89a / RGB332 / LZW 实现 | 流式写入，不累计整段录制内存，无运行时库 |
| 图像 | WPF Imaging / System.Drawing | 无第三方库的 PNG/JPEG/BMP 与像素处理 |
| 存储 | 本地 JSON 与 PNG/MP4/GIF | 原子写入、历史保留，与程序目录分离 |
| 测试 | 模板自带 xunit | 区域、标注、状态与数据规则可独立验证 |
| 构建与打包 | dotnet CLI / PowerShell | 沿用模板的严格构建和事务打包 |

Core 不引用 WPF；App 承担 Windows 适配与界面。UI 框架和目标框架在 Directory.Build.props 集中维护。后续 WGC、音频和 OCR 后端按模块扩展，不改动用户操作流程。

## 已知边界

第一版目标为 Windows 10 / 11 x64。运行无需 FFmpeg；N 版系统需要自身媒体组件。MP4 录制采用 CPU 色彩转换及系统编码，帧率需结合实际机器性能；GIF 使用 256 色。HDR 色彩、不同 DPI 的多屏、游戏与受保护窗口需专项验证。OCR、长截图、回放剪辑和音频同步安排在后续里程碑，具体状态以功能对照和源码为准。
