# 01 · 技术栈说明

## 架构与选型

| 职责 | 技术 | 理由 |
|---|---|---|
| 语言与运行时 | C# / .NET Framework 4.8 / x64 | 与 desk-pins 一致，系统运行时，免安装分发 |
| 界面 | WPF | 多窗口、图像绘制、输入事件与自定义工具栏 |
| 桌面接口 | Win32 P/Invoke | 热键、物理像素、无激活显示与鼠标穿透 |
| 静态截图 | 系统 GDI | 第一版兼容性优先，冻结桌面后框选 |
| 视频 | Windows Media Foundation + 可配置 FFmpeg | 系统 NV12/H.264 片段；FFmpeg 合并、剪辑/混音、硬件最终导出与 WebP |
| 音频 | NAudio.Wasapi 2.2.1 | 系统声/麦克风独立 PCM 与设备选择，暂停排除和时间线补静音 |
| OCR | Windows.Media.Ocr | Windows 已安装语言的离线引擎；SDK Contracts/WindowsRuntime 提供 net48 投影 |
| 联网识别 | HttpClient + JSON 协议 + Windows DPAPI | 可配置服务，明确请求，限大小/超时/取消和本机密钥 |
| 公式 / 二维码 | WpfMath 0.13.1 / ZXing.Net 0.16.11 | 本地 LaTeX 像素渲染及 QR 解码 |
| 表格 / 文档导出 | ZipArchive + OpenXML XML | 不依赖 Office 安装；测试用 Office SDK 独立校验 XLSX/Word |
| 动图 | 独立 GIF89a / RGB332 / LZW 实现 | 流式写入，不累计整段录制内存，无运行时库 |
| 图像 | WPF Imaging / System.Drawing | PNG/JPEG/BMP/TIFF、透明轮廓与标注像素处理 |
| 存储 | 本地 JSON、独立钉图/录制素材与图像文件 | 原子写入、分开保留上限，与程序目录分离 |
| 测试 | 模板自带 xunit | 区域、标注、状态与数据规则可独立验证 |
| 构建与打包 | dotnet CLI / PowerShell | 沿用模板的严格构建和事务打包 |

Core 不引用 WPF；App 承担 Windows 适配与界面。版本和目标框架在 Directory.Build.props 集中维护。现有截图仍用 GDI，后续可增加 WGC；服务商通过 [协议](04-联网服务协议.md) 适配，界面不绑定单一服务。

## 已知边界

目标为 Windows 10 / 11 x64。基础无音频 MP4/GIF 可使用系统组件；音频、WebP、剪辑、最终硬件编码及恢复需 FFmpeg/ffprobe，应用不自动下载安装。OCR 需要 Windows 语言组件，联网识别需要用户配置服务。真实设备同步、长期录制、混合 DPI、多屏、HDR、受保护窗口及游戏捕获需专项验收；批次代码完成不代表整个 PixPin 功能复刻完成。
