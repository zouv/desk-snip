# 05 · 第三方组件

DeskSnip 的桌面 UI 和运行时为 WPF / .NET Framework 4.8。下列组件通过 NuGet 获取，应用没有修改其源码；发行包保留 licenses/ 中的原许可文本。版本以各 csproj 为准。

| 组件 | 版本 | 用途 | 许可与来源 |
|---|---|---|---|
| NAudio.Wasapi / NAudio.Core | 2.2.1 | Windows 声音设备及 PCM 采集 | MIT，© Mark Heath；[源项目](https://github.com/naudio/NAudio)，[许可](../licenses/NAudio-MIT.txt) |
| ZXing.Net | 0.16.11 | 本地 QR 解码 | Apache-2.0，Michael Jahn / ZXing contributors；[源项目](https://github.com/micjahn/ZXing.Net)，[许可](../licenses/ZXing-Net-Apache-2.0.txt) |
| WpfMath / WpfMath.Shared | 0.13.1 | 本地 LaTeX 渲染 | MIT，© Alex Regueiro / WPF-Math Contributors；[源项目](https://github.com/ForNeVeR/wpf-math)，[许可](../licenses/WpfMath-MIT.txt) |
| Microsoft.Windows.SDK.Contracts | 10.0.19041.1 | 编译期 WinRT API 投影 | Microsoft Windows SDK 条款；[包](https://www.nuget.org/packages/Microsoft.Windows.SDK.Contracts/10.0.19041.1)，[条款](https://aka.ms/WinSDKLicenseURL) |
| System.Runtime.WindowsRuntime | 4.7.0 | .NET Framework 与 WinRT 桥接 | MIT；[许可](../licenses/WindowsRuntime-MIT.txt)、[原第三方声明](../licenses/WindowsRuntime-Notices.txt)；net48 发行优先使用系统程序集 |

System.Runtime.WindowsRuntime.UI.Xaml 为 SDK Contracts 的传递构建依赖，net48 运行使用 Windows/.NET Framework 组件。Windows OCR 引擎、语言、Media Foundation、WPF 和系统字体由 Windows 提供，本包没有复制 Windows 安装文件。

测试另外使用 xunit、Microsoft.NET.Test.Sdk 和 DocumentFormat.OpenXml 3.1.1；Office SDK 只用于独立校验文件，不进入应用发行包。XLSX/Word 导出不要求用户安装 Office。

FFmpeg/ffprobe 为用户自行配置的外部程序，可从 [FFmpeg 项目](https://ffmpeg.org/) 获取。DeskSnip 不下载或随包复制本机 FFmpeg；其许可证取决于用户所选发行版本和编译选项。基础无音频 MP4/GIF 可只用系统组件，其它增强功能在缺少 FFmpeg 时显示依赖提示。
