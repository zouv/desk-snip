# 04 · 联网识别服务协议

DeskSnip 使用可配置的 JSON 服务，不绑定具体厂商。服务可以部署在本机或 HTTPS 地址；服务商原始 API 与此协议不同，需要由适配服务转换。打开识别窗口不会联网，仅点击“请求服务”发送当前勾选图片和填写文字。

## 配置与请求

在“设置 → 联网服务”填写完整请求地址，例如 `https://example.com/recognize`。远程地址必须 HTTPS，本地模拟可用 `http://127.0.0.1:8080/recognize`，地址不能含账号密码或 fragment。超时 5–300 秒，默认 60。请求为 HTTP POST，Content-Type 和 Accept 为 application/json，不跟随重定向、不发送 Cookie。

密钥以 `Authorization: Bearer <key>` 发送，环境变量优先于本机 DPAPI 保存值；均未配置时不带 Authorization。不能把密钥放在地址中。偏好导出排除地址、环境变量名和密钥，只有点击“保存设置”会更新密钥。

```json
{
  "schema": 1,
  "operation": "translation",
  "imageBase64": "<PNG 的 Base64；仅发送原图时出现>",
  "text": "Sample text",
  "sourceLanguage": "auto",
  "targetLanguage": "zh"
}
```

operation 为 text/translation/table/formula/document。imageBase64 和 text 至少一个有内容；纯文字翻译可取消“发送原图”。语言代码传给服务，auto/zh 是默认值；具体支持范围由适配服务决定。图片不经过 URL 下载，服务自行解码 PNG。

## 响应

成功响应为 HTTP 2xx 和以下 JSON，schema 与 operation 必须对应请求；无需字段可以省略。每种操作的必需内容见表。

```json
{
  "schema": 1,
  "operation": "table",
  "text": "Sample source",
  "table": {
    "rows": [["名称", "数量"], ["Sample", "10"]],
    "merges": [{"row": 0, "column": 0, "rows": 1, "columns": 2}]
  }
}
```

| 操作 | 返回字段 | DeskSnip 使用 |
|---|---|---|
| text | 非空 text | 原图对照、校对、复制/保存 |
| translation | 非空 translatedText，可选 text 原文 | 原文/原图与译文对照、校对 |
| table | table.rows 和可选 merges | 单元格编辑、合并/拆分、排序、XLSX/CSV/TSV |
| formula | formulas 字符串数组，至少一条 | LaTeX 编辑和本地预览、源码/PNG |
| document | 非空 markdown，可选 assets | 基础 Markdown 预览、Word、带配图 ZIP |

表格坐标从 0 开始，rows 为矩形二维字符串数组，merges 不重叠；合并只显示左上格，原单元格内容保留，拆分恢复。插删行列会解除合并，跨行合并需要先拆分再排序。XLSX 把单元格写为文本，不执行公式。

文档示例：

```json
{
  "schema": 1,
  "operation": "document",
  "markdown": "# Sample\n\n![Sample](images/sample.png)\n\n$$x^2+1$$",
  "assets": [{"name": "sample.png", "mime": "image/png", "base64": "<PNG Base64>"}]
}
```

配图名称仅允许 1–80 位字母/数字/下划线/短横线，加小写 png/jpg/jpeg 扩展名，MIME 与文件内容一致、名称唯一；Markdown 引用 images/名称。预览不会加载远程图或运行 HTML，公式语法不支持时保留源码。Word 的公式为 LaTeX 文本；PDF、整篇 LaTeX、原译图覆盖及更多公式格式未实现。

长文预览只显示前 20 万字符/2000 段，源码和文件导出保留完整内容。

## 上限与失败

- 请求图片 Base64 最多 2800 万字符，文字最多 50 万字符；图片最大 3200 万像素，单边最多 20000 像素。
- HTTP 响应最多 40 MiB。text/translatedText/markdown 合计最多 200 万字符。
- 表格最多 2000 行、200 列、10 万格，单格最多 5 万字符；XLSX 单格最大 32767 字符，超出会提示，CSV 可继续导出。
- formulas 最多 100 条、每条最多 10 万字符；本地预览最多 4096 字符、嵌套 32 层，超出仍可保存源码。
- assets 最多 30 张、单张 Base64 最多 800 万字符，合计最多 2800 万字符、4800 万像素。

认证失败、重定向、非协议 JSON、操作不符、超限、无效图片、超时与取消均保留原图和旧结果。成功和编辑后的原图/请求文字/结果保存为本机 recognition/last-session.json，控制台可恢复最近一份，无需联网。不会保存请求密钥到结果中。

## 本地验证

`sh manager.sh test` 的 RecognitionServiceTests 使用随机本机端口的模拟 HTTP 服务，验证五种操作、PNG/语言/请求头和响应；其它测试验证取消/超时/错误格式、凭据、编辑与导出。输入为合成内容，不使用个人截图；这些验证不代表任何实际厂商的识别质量。
